# Cross Club Pickleball redesign

A clearer, mobile-friendly redesign concept for the Cross Club Pickleball League website.

## Current public site map

- Home
- Registration: club, player, local league
- Leagues: mixed, gender, local, ladder
- League dashboard / standings
- About Us
- Contact Us and incident report

## Preview direction

Lead with three visitor paths: join as a player, bring in a club, and view standings. Group league formats in one section. Keep existing registration and standings links until the underlying workflows are connected.

The `redesign` branch contains the Netlify-ready static preview. It is an unofficial review concept and does not replace the live site.
